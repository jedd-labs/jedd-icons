Every icon component accepts the props below **plus all standard SVG
attributes** (`className`, `onClick`, `style`, `aria-*`, `focusable`, …).

<TypeTable
  type={{
    size: { type: "number | string", default: "24", description: "Sets both width and height." },
    color: { type: "string", default: '"currentColor"', description: "Sets the stroke color." },
    strokeWidth: { type: "number | string", default: "2", description: "Stroke width." },
    absoluteStrokeWidth: { type: "boolean", default: "false", description: "Keep a constant visual stroke width regardless of size." },
  }}
/>

### Defaults at a glance

| Prop | Default | Notes |
| --- | --- | --- |
| `size` | `24` | px when numeric |
| `color` | `currentColor` | inherits text color |
| `strokeWidth` | `2` | |
| `absoluteStrokeWidth` | `false` | see below |

To change these defaults for every icon, wrap your app in `JeddProvider` — see
[Global styling](/docs/react/global-styling).

import { getMDXComponents } from "@/components/mdx";
import StylingModel from "../../_shared/styling-model.mdx";

## Exported types

```ts
import type {
  IconProps,
  JeddIcon,
  JeddProviderProps,
  IconNode,
} from "@jedd-icons/react";
```

- **`IconProps`** — the props every icon accepts (extends `SVGProps`).
- **`JeddIcon`** — the type of an icon component (`ForwardRefExoticComponent`).
- **`JeddProviderProps`** — the props `JeddProvider` accepts.
- **`IconNode`** — the raw icon geometry tuple.
