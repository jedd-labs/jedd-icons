An icon plays its **default** unless you pick another with `animation` or a
named trigger (`animateOnHover="pointing"`). Icons with their own animations
choose one as their default (★ below); the rest play the fallback, `draw`,
unless you set another with [`fallbackAnimation`](/docs/animated/global-styling#fallback-animation).

## Presets

Every icon can play these, whatever it depicts:

<PresetDemo />

| Name | What it does |
| --- | --- |
| `draw` | Draws each stroke in. The fallback default of icons without their own. |
| `draw-loop` | Undraws each stroke and draws it back — made for `loop`. |
| `pulse` | Shrinks and springs back. |
| `wiggle` | Rocks side to side. |
