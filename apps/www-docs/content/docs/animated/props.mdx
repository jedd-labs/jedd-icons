Animated icons accept **every prop of `@jedd-icons/react`** — `size`, `color`,
`strokeWidth`, `absoluteStrokeWidth` and all SVG attributes (see
[React props](/docs/react/props)) — plus the props below.

## Triggers

<TypeTable
  type={{
    animate: { type: "boolean | AnimationName", default: "false", description: "Plays while true. A name also picks the animation." },
    animateOnHover: { type: "boolean | AnimationName", default: "false", description: "Plays while hovered." },
    animateOnTap: { type: "boolean | AnimationName", default: "false", description: "Plays once per press, to the end." },
    animateOnView: { type: "boolean | AnimationName", default: "false", description: "Plays when it's in the viewport." },
    animateOnViewOnce: { type: "boolean", default: "true", description: "Only the first time it's in view." },
    animateOnViewMargin: { type: "string", description: 'IntersectionObserver root margin, e.g. "0px 0px -20% 0px".' },
    animation: { type: "AnimationName", default: '"default"', description: "Which animation plays." },
  }}
/>

`AnimationName` suggests the icon's own animations, `"default"` and the
presets. Any other name plays `default`.

## Options

<TypeTable
  type={{
    delay: { type: "number", default: "0", description: "Milliseconds before it starts." },
    loop: { type: "boolean", default: "false", description: "Repeat while the trigger is active." },
    loopDelay: { type: "number", default: "0", description: "Milliseconds between loops." },
    completeOnStop: { type: "boolean", default: "false", description: "Finish the current run before returning to rest when stopped." },
    persistOnAnimateEnd: { type: "boolean", default: "false", description: "Stay where the animation ended instead of returning to rest." },
    initialOnAnimateEnd: { type: "boolean", default: "false", description: "Snap back to rest, without a transition, when a run ends." },
  }}
/>

## AnimateIcon

`<AnimateIcon>` takes the same triggers and options, which apply to every icon
inside it, plus:

<TypeTable
  type={{
    asChild: { type: "boolean", default: "false", description: "Attach the triggers to its only child instead of wrapping it in a <span>." },
    children: { type: "ReactNode", required: true, description: "The element (or icons) to animate." },
  }}
/>

and any HTML attribute, passed to the `<span>` (or merged onto the child with
`asChild`).

An icon inside follows the wrapper's trigger. Its own `animation` and options
win over the wrapper's; its own trigger, when active, takes over.

## Exported types

```ts
import type {
  AnimatedIconProps,
  AnimatedJeddIcon,
  AnimateIconProps,
  AnimationName,
  AnimationOptions,
  AnimationTriggers,
} from "@jedd-icons/react-animated";
```

- **`AnimatedIconProps`** — the props every animated icon accepts.
- **`AnimatedJeddIcon`** — the type of an animated icon component, with its
  `animations` list.
- **`AnimateIconProps`** — the props of `<AnimateIcon>`.
- **`AnimationTriggers`** / **`AnimationOptions`** — the two groups of props
  above.
