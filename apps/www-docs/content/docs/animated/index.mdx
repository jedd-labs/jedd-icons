`@jedd-icons/react-animated` is the animated edition of
[`@jedd-icons/react`](/docs/react): **every icon, under the same name, with the
same props** — plus props that play an animation on hover, on click, when it
scrolls into view, or whenever you say.

Hover the icons below:

<AnimatedIconGrid />

## How it works

- **Same icons, same look at rest.** Each icon renders through
  `@jedd-icons/react`, so an animated icon that isn't playing is pixel-for-pixel
  the static one. Swapping the import is the whole migration.
- **Every icon animates.** All icons get the [presets](/docs/animated/animations#presets)
  — `draw`, `draw-loop`, `pulse`, `wiggle`. Many also have animations designed
  for what they depict: the arrow points, the trash lid lifts, the loader
  spins.
- **Built on [Motion](https://motion.dev).** Motion is a peer dependency, so
  apps that already use it don't ship it twice.
- **Respects reduced motion.** Visitors who ask their OS for reduced motion see
  still icons.
